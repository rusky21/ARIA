# AI Supporter — Frontend

Клиентская часть проекта (React + Vite). Запускается только вручную, отдельно от бэкенда. Подключается к бэкенду по WebSocket.

## Запуск для разработки

```bat
npm install
npm run dev
```

Vite-сервер откроется на `http://localhost:5173` и будет проксировать запросы `/ws`, `/events`, `/api` на `http://localhost:5000` (локальный бэкенд).

## Сборка

```bat
npm run build
```

Готовые файлы появятся в `dist/`.

## Подключение к бэкенду на другом сервере

Создай файл `.env` в этой папке и укажи адрес сервера:

```
VITE_WS_URL=ws://192.168.1.50:5000/ws
VITE_API_URL=http://192.168.1.50:5000
```

(замени `192.168.1.50` на реальный IP или домен машины, где запущен бэкенд).

Если `.env` нет — фронт подключится к бэкенду на том же адресе, с которого сам открыт (для локальной разработки).

## Требования

- Node.js (рекомендуется 20+)
- Запущенный бэкенд (см. README репозитория AI-SUPPORTER-BACKEND)
